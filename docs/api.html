API

Public surface

Stable entry points for Glue apps. Import as import glue after pip install glue-ui.

glue.expose

Decorator (or function) to expose Python callables to JavaScript.

@glue.expose
def add(a, b):
    return a + b

@glue.expose('renamed')
def internal_name():
    return 1

From JS: await glue.add(1, 2)() — note the extra () for the callback / await pattern.

glue.init

glue.init(
    path='ui',
    allowed_extensions=['.js', '.html', '.txt', '.htm', '.xhtml', '.vue'],
    js_result_timeout=10000,
    app_name=None,
)
  • path — UI root folder (default ui / web discovery).
  • allowed_extensions — files scanned for glue.expose(...) so Python can call those JS names.
  • js_result_timeout — ms to wait for JS return values.
  • app_name — unlocks default settings path ~/.{app_name}/{app_name}.json.

glue.settings / save_settings / settings_path

data = glue.settings()                 # or settings('/path.json')
glue.save_settings(data)               # creates dirs on first write
path = glue.settings_path()            # requires app_name

glue.sleep / glue.spawn

glue.sleep(1.0)
greenlet = glue.spawn(my_fn, arg1, kw=2)

Gevent-friendly; prefer these over blocking stdlib sleep in Glue apps.

glue.show

Open additional pages after start (same hosts / geometry rules).

glue.show('other.html')

glue.get_webview_windows

Returns the list of PyWebView window objects for advanced control when the host is PyWebView.

windows = glue.get_webview_windows()

glue.register_glue_routes

Attach Glue routes to a custom Bottle app before glue.start(app=...). Usually automatic.

import bottle
import glue

app = bottle.Bottle()
glue.register_glue_routes(app)
glue.start(app=app)

JavaScript API

Include the bridge on every page before your app scripts:

<script type="text/javascript" src="/glue.js"></script>

Expose to Python

glue.expose(fn) or glue.expose(fn, "name") registers a JS function so Python can call glue.name()().

glue.expose(say_hello_js);
function say_hello_js(x) {
  console.log(x);
}

Call Python

Exposed Python functions appear on glue. Call with args, then an extra () to run (returns a Promise — use await).

let sum = await glue.add(1, 2)();
glue.add(1, 2)(console.log);  // callback style

Window identity

When you pass title= to glue.start, /glue.js applies it to document.title so Chrome/Edge captions match.

Geometry helpers

On Chrome/Edge, /glue.js can apply size / position / per-page geometry via resizeTo / moveTo after load.

Glue is a fork of Eel. Install with pip install glue-ui · GitHub
