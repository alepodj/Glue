Glue

A little Python library for making Desktop applications with web technologies HTML/CSS/JS.

Glue

The pitch

If you already speak the web,
you already speak desktop.

Glue hosts a local window, then lets Python and JavaScript call each other. No Electron ceremony. No new UI framework. Just HTML, CSS, JS — and Python where it belongs.

Three lines to a window

The simplest Glue app

Point Glue at a folder of UI files, then open a page. That is enough to ship a desktop window. 

import glue

glue.init()
glue.start('index.html')

Two directions · same bridge

Frontend ↔ Backend

Each direction is its own call. Expose on one side, invoke from the other.

Front → Back

JavaScript calls Python

UI asks the backend to do work, then reads the return value.

Frontend · JavaScript
glue.bridge_echo({
  message: "hello from the UI"
})();
idle

waiting

Backend · Python
@glue.expose
def bridge_echo(payload):
    return {
      "echo": payload["message"],
      "from": "python",
    }
idle
Back → Front

Python calls JavaScript

Backend pushes into the UI through an exposed JS function.

Backend · Python
glue.bridge_on_js({
  "message": "hello from Python"
})()
idle

waiting

Frontend · JavaScript
glue.expose(bridge_on_js);
function bridge_on_js(payload) {
  return {
    echo: payload.message,
    from: "javascript",
  };
}
idle

Why it feels easy

  • Your technologies, unchanged Bring the HTML, CSS, JS, and libraries you already use — now inside a desktop window.
  • Python does the hard parts Files, processes, science libraries — one @glue.expose away.
  • Ships as an app Chromium app-mode by default. Package later with PyInstaller.

Less framework. More Glue.
