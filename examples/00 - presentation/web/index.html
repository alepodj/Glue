The pitch

If you already speak the web,
you already speak desktop.

Glue hosts a local window, then lets Python and JavaScript call each other. No Electron ceremony. No new UI framework. Just HTML, CSS, JS — and Python where it belongs.

Three lines to a window

  1. glue.init('web')Serve your frontend
  2. @glue.exposeShare Python with JS
  3. glue.start('index.html')Open the app

Familiar chrome · better visuals

Classic menus. Modern surface.

Build the UI you want in the browser — including the patterns people already know from desktop software.

})();

Python
@glue.expose
def bridge_echo(payload):
    return {
      "echo": payload["message"],
      "from": "python",
    }
