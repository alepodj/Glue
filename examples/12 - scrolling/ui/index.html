Natural page scrolling

This application uses the default glue.init() and glue.start() calls. The content is intentionally long: only the page area should scroll while the window controls remain fixed and unaffected above it.

Section 01

Scroll down and watch the title bar. Its minimize, maximize, and close controls stay outside the scrolling content.

Section 02

The scrollbar begins below Glue's simulated native title bar instead of extending behind the window controls.

Section 03

No window options, overflow declarations, or special layout workarounds are used by this example.

Section 04

The title bar owns the top of the viewport while the document body owns the remaining scrollable area.

Section 05

Regular wheel, touchpad, keyboard, and scrollbar navigation should all move only this content.

Section 06

Long application pages can therefore behave like normal web pages without interfering with window chrome.
